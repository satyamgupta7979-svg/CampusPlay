# CampusPlay — Backend API

Production-ready REST API for CampusPlay sports tournament management built with Express.js, MongoDB, and Mongoose.

## Quick Start

1. Ensure MongoDB is running on `mongodb://127.0.0.1:27017`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run seed script:
   ```bash
   npm run seed
   ```
4. Start backend server:
   ```bash
   npm run dev
   # or npm start
   ```

Backend runs on: `http://localhost:5000/api`
